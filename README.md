# Retail Sales Analytics Project

مشروع تطبيقي متكامل لتحليل بيانات المبيعات، يهدف إلى توضيح كيف تتكامل أدوات تحليل البيانات المختلفة داخل مشروع واحد؛ بداية من قاعدة البيانات وSQL، مرورًا بـ Python وEDA وPower BI، وصولًا إلى التحليل التنبؤي.

---

## Project Objective

الهدف من المشروع هو بناء رحلة تحليلية متكاملة تبدأ من البيانات الخام وتنتهي بنتائج قابلة للاستخدام في اتخاذ القرار.

سيتم استخدام نفس البيانات خلال جميع مراحل المشروع حتى يكون واضحًا كيف تتغير وظيفة كل أداة داخل دورة التحليل.
